# Microsoft Data Sources Validation Matrix

Every metric displayed in the portal is mapped below to its verified Microsoft documentation source. Where Microsoft does not expose an automated REST API or requires PowerShell / licensing / manual tracking, this matrix explicitly states the boundary.

**Classification Legend:**
- **AVAILABLE VIA API**: Collected directly via Microsoft Graph v1.0, Graph Beta (flagged `BetaDependency`), or Office 365 Management Activity API.
- **AVAILABLE VIA POWERSHELL**: Collected via Security & Compliance PowerShell (`Connect-IPPSSession`) snapshot bridge.
- **MANUAL / CUSTOMER INPUT**: Tracked by Managed Service engineers / analysts inside the portal (`ManagedServiceActivity` or `Recommendation`).
- **NOT CURRENTLY AVAILABLE THROUGH A SUPPORTED INTERFACE**: Not natively exposed via a supported GA REST API; surfaced explicitly as `ApiUnsupported` or `Unavailable`.
