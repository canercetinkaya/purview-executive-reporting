# Threat Model (OWASP Top 10 & OWASP API Security Top 10)

| Threat Category | Attack Scenario | Mitigation Implemented | Verification Test |
| :--- | :--- | :--- | :--- |
| **API1: Broken Object Level Authorization (BOLA / IDOR)** | `CustomerExecutive` from Customer A modifies URL `:customerId` to access Customer B's Purview risks or CSV exports. | `requireCustomerScope()` invokes `assertCustomerAccess(principal, customerId)` server-side on every customer route, returning HTTP `403`. | `api.integration.test.ts` (Contoso requesting Northwind returns `403`) |
| **API2: Broken Authentication** | Missing, forged, or wrong-audience JWT submitted in `AUTH_MODE=entra`. | `jose` `jwtVerify()` against Microsoft Entra JWKS verifying signature, `iss`, and `aud`. Missing/invalid tokens return `401`. | `api.integration.test.ts` (`AUTH_MODE=entra` missing token -> `401`) |
| **API3 / A01: Broken Function Level Authorization** | `CustomerReader` invokes `POST /managed-service/activities` or `GET /reports/export`. | `requirePermission()` checks `ROLE_PERMISSIONS` matrix per endpoint. | `api.integration.test.ts` (`CustomerReader` -> `403` on export & write) |
| **A03: Injection (SQLi & CSV Formula Injection)** | Malicious SQL parameters or spreadsheet formula payloads (`=CMD|...`) inside Purview policy names. | Parameterized `pg` queries (`$1`, `$2`) exclusively; `sanitizeCsvCell()` neutralizes formula prefixes (`=+-@`). | `security.test.ts` (CWE-1236 unit test + schema verification) |
| **API4: Unrestricted Resource Consumption** | Flood of heavy report/export calls or unbounded Graph `@odata.nextLink` loops. | `express-rate-limit` middleware + `maxPages` safety cap on `GraphHttpClient.getPagedCollection`. | `connectors.test.ts` & API rate-limit middleware |
| **API10 / SSRF** | Arbitrary external URLs passed via collector pagination or webhooks. | Collectors exclusively target fixed Microsoft hosts (`login.microsoftonline.com`, `graph.microsoft.com`, `manage.office.com`). `PowerShellComplianceBridgeConnector` sanitizes `customerId` via regex before path resolution. | `Invoke-PurviewComplianceCollect.ps1` parameter validation + connector tests |
| **A09: Security Logging & Secret Leakage** | Access tokens or `client_secret` accidentally written to error logs during HTTP 429/5xx failures. | `redactSensitiveFields()` scrubs all token/secret/Bearer keys recursively; API never leaks stack traces in `NODE_ENV=production`. | `security.test.ts` |
